Quickstart

Send your key in the X-API-Key header. Every language works; here are the short versions.

cURL
curl -s https://YOUR-HOST/api/analyze \
  -H "X-API-Key: $DR_AISHU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"high fever, body aches and chills for 3 days with a dry cough"}'
Python
import os, requests

API = os.environ["DR_AISHU_URL"]        # e.g. https://dr-aishu.onrender.com
KEY = os.environ["DR_AISHU_API_KEY"]

def diagnose(text, **ctx):
    r = requests.post(
        f"{API}/api/analyze",
        headers={"X-API-Key": KEY},
        json={"text": text, **ctx},
        timeout=30,
    )
    r.raise_for_status()
    return r.json()

out = diagnose("burning when I pee and going very often, lower abdominal pain")

print(out["severity"]["triage"])            # 'self_care'
print(out["diagnoses"][0]["name"])          # 'Urinary Tract Infection'
for m in out["medicines"]["recommended"]:
    print(m["name"], m.get("frequency"))
for block in out["routine"]["blocks"]:
    print(block["time"], block["title"])
Image upload (Python)
with open("lab_report.png", "rb") as fh:
    r = requests.post(
        f"{API}/api/analyze-image",
        headers={"X-API-Key": KEY},          # do not set Content-Type; requests adds the boundary
        files={"image": fh},
        data={"text": "reports fever for four days"},
        timeout=60,
    )
print(r.json()["image_analysis"]["ocr"]["text"])
JavaScript
const res = await fetch(`${API}/api/analyze`, {
  method: "POST",
  headers: {
    "X-API-Key": process.env.DR_AISHU_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ text: "sore throat and fever for 2 days" }),
});
const { severity, diagnoses, medicines, routine } = await res.json();

Rate limits

Every response carries X-RateLimit-Limit-Minute, X-RateLimit-Remaining-Minute, X-RateLimit-Limit-Day, X-RateLimit-Remaining-Day and X-RateLimit-Tier. A refused request returns 429 with a Retry-After header.

Response shape

Analysis results are top-level keys, not nested under an analysis object.

200 OK
{
  "disclaimer": "...",
  "extracted":  { "symptoms": [...], "duration": {...}, "vitals": {...} },
  "diagnoses":  [ { "id": "...", "name": "...", "confidence": 64.0 } ],
  "severity":   { "score": 5, "triage": "see_doctor", "reasons": [...] },
  "medicines":  { "recommended": [...], "prescription_only": [...], "timetable": [...] },
  "routine":    { "name": "...", "blocks": [...] },
  "solutions":  { "problems": [ { "label": "...", "steps": [...], "covered_by": [...] } ],
                  "condition": { "name": "..." }, "notes": [...] },
  "case":       { "case_id": "...", "stored_for_training": false }
}

Status codes

  • 401 — missing or invalid key.
  • 403 — the key's tier lacks the required scope.
  • 404 — unknown case or key.
  • 413 — image over 12 MB.
  • 415 — unsupported image type.
  • 422 — request failed validation.
  • 429 — rate limit reached; respect Retry-After.

Safety and privacy

What you may and may not do

  • Dr. Aishu is an educational triage aid. Do not present its output as a diagnosis or prescription.
  • Emergency cases deliberately return no medicines. Surface that guidance prominently in your UI.
  • Show the disclaimer field to your users.
  • Do not send real patient data unless you have a lawful basis and consent.

What we store

  • Your key is stored only as a SHA-256 hash; the plaintext is shown once.
  • Free text is saved only when the request sets consent_share: true, and direct identifiers are stripped first.
  • DELETE /api/data/case/{case_id} erases a case and its feedback.
